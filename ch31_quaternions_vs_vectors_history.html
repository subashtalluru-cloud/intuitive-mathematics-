Same Rotation, Two Rival Notations — Only One Survived Everyday Use
Hamilton's 1843 quaternions could describe 3D rotation, but at a real notational cost. Gibbs and Heaviside's 1880s simplification — the vector algebra this chapter teaches — computes the identical physical rotation with dramatically less machinery.
Hamilton's Quaternions 1843
A point (1,0,0) rotated 90 degrees about the z-axis requires a 4-component quaternion object and the sandwich product q*v*q-inverse, involving many individual multiplications.
Gibbs/Heaviside Vector Algebra 1880s
The identical rotation: apply the 2x2 rotation matrix [[0,-1],[1,0]] directly to (1,0) - a single, direct matrix-vector multiplication, no auxiliary object required.
Both methods, applied to (1,0,0), land on the identical rotated point (0,1,0) - confirmed by direct computation. The vector/matrix approach became standard not because quaternions were wrong, but because it's a strictly simpler tool for the everyday case.
