|x| Is Secretly a Two-Piece Function
Click values of x to see which piece of the absolute value definition fires — and why the graph forms a clean V-shape.
|x| = x if x≥0;    |x| = −x if x<0
At x=0, both pieces agree (both give 0) — that's exactly why the graph connects smoothly into a clean V-shape with no gap or jump, satisfying both mutual exclusivity and exhaustiveness at the meeting point.
