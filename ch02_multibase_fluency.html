One Quantity, Four Costumes
Drag the slider. The underlying quantity never changes — only its "costume" (which base is used to write it down) does. Watch the bucket-widths shrink as base grows.

The quantity is identical in every row — same pebbles, same amount. Only the bucket sizes differ: binary buckets are worth 1,2,4,8…; hex buckets 1,16,256…; the ancient Babylonian system used buckets worth 1, 60, 3600… which is why we still have 60 minutes in an hour today.
