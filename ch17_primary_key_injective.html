Why Primary Keys MUST Be Injective
A database's primary key must map every row to a UNIQUE identifier. Click "Add row" and watch the arrow diagram — the 4th row will collide with an existing key.
A database's primary key column establishes, by definition, an injective function from rows to key values. Two rows mapping to the identical ID isn't a minor bug — it's a visible violation of the injectivity arrow-diagram rule from earlier in this chapter, now with real financial or medical data at stake.
