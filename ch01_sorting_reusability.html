One Sorting Rule, Any Kind of Data
A sorting algorithm only needs ONE thing: a way to compare two items. Click each dataset — watch the same visual bars-and-swaps process handle wildly different data.
The algorithm never asks "are these numbers or names?" It only asks "is item A less than item B?" — a single abstracted question that works identically whether "less than" means numerically smaller, alphabetically earlier, or chronologically earlier.
