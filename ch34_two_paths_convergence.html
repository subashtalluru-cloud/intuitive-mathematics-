Chapter 15's Farmer, Solved Two Completely Different Ways
x+y=10 chickens and cows' heads, 2x−y=5 from the legs equation. Chapter 15 solved this by hand elimination. This Part's entire machinery — vectors, matrices, determinants, inverses — solves the identical system a totally different way. Compare both paths.
Chapter 15: Elimination
1. x + y = 10
2. 2x − y = 5
3. Add equations: 3x = 15
4. x = 5
5. Substitute: 5 + y = 10, so y = 5
This Part: Matrix Inversion
1. A = [[1,1],[2,−1]], b = (10,5)
2. det(A) = (1)(−1) − (1)(2) = −3
3. A⁻¹ = (1/−3)[[−1,−1],[−2,1]]
4. x = A⁻¹b
5. x = (5, 5)
Both paths: x=5, y=5. Same answer, zero shared steps.
This is the exact closing move of Part VII: elimination's original three-outcome classification (unique solution, no solution, infinite solutions) was, this whole time, precisely governed by whether this Part's own determinant is nonzero.
