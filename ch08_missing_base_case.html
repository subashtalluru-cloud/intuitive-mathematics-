Spot What's Missing
Here's a "proof" that all horses are the same color, using only an inductive step. Something essential is missing. Click to reveal it.
Claim: All horses are the same color.

Inductive step: Assume any group of k horses are all the same color. Consider a group of k+1 horses. Remove one horse — the remaining k are the same color (by assumption). Put it back and remove a different horse — those remaining k are also the same color (by assumption). The two overlapping groups share horses, so all k+1 horses must be the same color.

Conclusion: By induction, all horses are the same color.
Mathematical induction is fully deductive — nothing like "gathering more supporting cases" (the marble-bag pattern from Chapter 3). But it still needs BOTH ingredients. Skip either one and the whole ladder collapses, no matter how convincing the other looks.
