Stacking Transformations on f(x) = x²
Toggle each transformation on or off. Watch how f(x) = x² becomes something like −2(x−3)² + 4.
Each toggle corresponds to one algebraic move: shift right → replace x with (x−3); stretch → multiply by 2; reflect → multiply by −1; shift up → add 4. Combined: −2(x−3)²+4.
