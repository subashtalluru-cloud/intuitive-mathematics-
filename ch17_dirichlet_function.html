The Dirichlet Function — A Function With No Formula
D(x) = 1 if x is rational, 0 if x is irrational. Click each number to plot D(x) on the graph below — this is a perfectly legitimate function despite having no algebraic formula and no continuous curve.
"A function must have a formula" is a misconception. A function is, at its deepest logical foundation, simply a set of ordered pairs satisfying one membership condition. Notice the plotted points never connect into a curve — they jump chaotically between the two horizontal lines, y=0 and y=1, no matter how closely you zoom in.
