Rotate-Then-Scale vs Scale-Then-Rotate — Genuinely Different
Same two operations, same starting vector, only the ORDER changes. Watch both final positions land in different places — matrix multiplication is not commutative, for the identical reason function composition wasn't in Chapter 21.
Scale first, then rotate
Rotate first, then scale
This isn't a special quirk of THIS scale-and-rotate pair — it's the general rule. Only in special cases (like two rotations combined with each other) does order happen not to matter.
