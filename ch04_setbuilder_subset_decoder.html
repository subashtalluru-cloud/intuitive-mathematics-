Decoding Set-Builder Notation
Click each part of the notation below to see what it means. Then test yourself on subset relations.
A = { x | x ∈ ℕ, x < 6 }
Click any part of the notation above to decode it.
A = {1, 2, 3, 4, 5} — test which relation is TRUE for each pair below
The bar "|" always means "such that" — everything after it is a filter, not a list. This is the same logic a database WHERE clause uses: SELECT x WHERE x ∈ ℕ AND x < 6.
