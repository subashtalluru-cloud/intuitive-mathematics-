Type a String — Watch This 2-State Machine Decide, Symbol by Symbol
This tiny machine recognizes "one or more a's" (regex: a+). Type any string and trace exactly how it moves between states, one character at a time, with no memory beyond its current state.
"Finite" refers specifically to the fixed, bounded number of internal states — not to any limit on the length of strings the machine can process; a 2-state machine handles strings of any length whatsoever.
