Recursion Is Induction, Running Backward
Click "Call factorial(5)" and watch the call stack build — the base case and inductive step of induction are exactly the base case and recursive case of this function.
Proving this function terminates correctly, for every possible input, is literally a proof by induction: base case (n=0 returns 1, correctly) + inductive step (if factorial(n-1) is correct, factorial(n) is correct because it just multiplies by n). Structural mirror images — this is why induction is the standard tool for proving recursive algorithms correct.
