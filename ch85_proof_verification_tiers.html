Three Genuinely Different Roles Computers Play in Modern Mathematics
Click each tier to see exactly what kind of guarantee it provides — these are not interchangeable levels of "computer help," but three structurally distinct relationships between human insight and machine verification.
Tier 1: Computer-Assisted Proof (e.g., the Four Color Theorem, 1976)
A human-designed proof strategy where a computer mechanically checks one large but finite, well-defined component (here, ~1,900 map configurations) that no human could realistically verify by hand. The overall conceptual structure remains fundamentally human.
Tier 2: Formally Verified Proof (e.g., using Lean, Coq, Isabelle)
The ENTIRE logical structure of a proof — every single step — is mechanically checked against basic rules of inference, with zero possibility of a human oversight slipping through unnoticed. A considerably stronger guarantee than Tier 1's finite-case-checking alone.
Tier 3: Machine-Learning-Suggested Conjecture
A machine learning system flags a statistically plausible pattern across a large dataset. This is NOT a proof of any kind — only a data-driven suggestion a human researcher must still independently, rigorously prove or refute using traditional mathematical toolkit before it can be accepted as a theorem.
No current computational or machine learning system can, on its own, formulate genuinely meaningful new mathematical questions or construct the novel conceptual insight most new proofs still require.
