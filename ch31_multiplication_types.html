Two Vector Multiplications — Only One Gives Back an Arrow
"Vector multiplication always yields a vector" is false. Click both operations on the same starting vector A — watch one produce a genuine arrow, the other collapse to a single plain number with no direction at all.
Scalar multiplication: 3 x A
Dot product: A . B
This distinction matters practically: code expecting a vector back from a dot product, or a scalar back from scalar multiplication, will fail in exactly the way a type mismatch would.
