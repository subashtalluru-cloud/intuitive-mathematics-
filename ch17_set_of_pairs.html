A Function Is Secretly Just a Set of Pairs
Forget "machine" for a moment. At its deepest foundation, a function IS a set of ordered pairs — points on a plane. Click to add pairs, and test the ONE rule that makes the set legitimate.
The formal definition is just: a subset of ordered pairs where every first-coordinate (x-value) appears exactly once. This is exactly the vertical-line test from Chapter 18, seen from its most fundamental angle — two points sharing an x-coordinate is a visibly vertical pair, disqualifying the set.
