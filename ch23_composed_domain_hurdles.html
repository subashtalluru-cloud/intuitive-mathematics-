Two Hurdles, Not One — Composed Domain Restrictions
f(x) = x−4 (accepts everything). g(x) = √x (rejects negatives). Click x-values on the number line and watch which ones clear BOTH hurdles.
f(x)=x−4 alone accepts EVERY real number (green line, full domain). But g(f(x))=√(x−4) only works when x≥4 (shrunk domain) — because the SECOND machine rejects whatever negative output the first hands it, even though the first never complained.
