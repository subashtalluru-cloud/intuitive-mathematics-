f(g(x)) vs. g(f(x)) — Order Matters
f(x) = x + 3 (add 3). g(x) = 2x (double). Pick a starting number and watch how the two orderings diverge.
f(g(x)): double, then add 3
g(f(x)): add 3, then double
Function composition is generally order-dependent — unlike multiplication of ordinary numbers. Feeding the SAME input through the SAME two machines in a different order produces a genuinely different final output.
